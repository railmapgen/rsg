# 地下鉄案内標識ジェネレーター ガイド

## 基本操作
- `新しい要素を追加` を押して要素を追加します。
- SVG プレビュー内の要素をクリックすると選択できます。
- 右側パネルでスタイル、分割線、全体配置、幅、特殊属性を編集できます。
- 要素は SVG プレビュー上で直接ドラッグして並び順を変更できます。

## 編集のコツ
- 一部の文字要素は内容に応じて幅が自動調整されます。
- 手動幅に対応した要素は、`自動` のままなら自動幅を使います。
- スタイル選択ウィンドウには検索欄があります。
- 一部の路線要素は、パレット選択後に路線番号や名称を自動入力できます。

## プレビューと書き出し
- 要素を削除エリアへドラッグすると削除できます。
- `すべて削除` は 1 つの初期要素にリセットします。
- `PNG`、`SVG`、`JSON` で書き出せます。
- `JSON` の読み込みでは保存内容を復元し、可能な限り旧データにも対応します。

## モバイル操作
- SVG が画面幅を超える場合、プレビューを横にスワイプできます。
- タッチ端末では少し長押ししてからドラッグしてください。
- ドラッグ中に左右端へ近づくと、プレビューが自動で横スクロールします。
