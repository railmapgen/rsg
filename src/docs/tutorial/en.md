# Metro Sign Generator Guide

## Basic workflow
- Click `Add New Element` to create an element.
- Click an element in the SVG preview to select it.
- Edit its style, split line, alignment, width, and special properties in the right panel.
- Drag elements directly inside the SVG preview to reorder them.

## Editing tips
- Some text-based elements adjust width automatically from their content.
- Some elements support manual width. If you leave width on `Auto`, the generator uses the automatic width.
- Use the style picker search box to find a style quickly.
- After choosing a palette, related line fields can be filled automatically for supported line elements.

## Preview and export
- Drag an element to the delete area to remove it.
- Use `Delete All` to reset the canvas to one default element.
- Export is available as `PNG`, `SVG`, and `JSON`.
- Importing `JSON` restores a saved project and keeps old save compatibility where possible.

## Mobile tips
- Swipe horizontally in the preview area when the SVG is wider than the screen.
- Touch and hold briefly before dragging an element.
- While dragging near the left or right edge, the preview will auto-scroll.
