# 地鐵導視生成器教學

## 基本操作
- 點擊 `添加新塊` 來新增元素。
- 在 SVG 預覽區點擊元素即可選中它。
- 右側面板可以修改樣式、分割線、整體對齊、寬度和特殊屬性。
- 可以直接在 SVG 預覽中拖曳元素來調整順序。

## 編輯建議
- 部分帶文字的元素會根據內容自動調整寬度。
- 支援手動寬度的元素，如果保持為 `自動`，會繼續使用自動寬度。
- 樣式選擇視窗帶有搜尋欄，樣式較多時建議直接搜尋。
- 某些線路類元素在選擇調色盤後，會自動帶入線路編號或名稱。

## 預覽與匯出
- 將元素拖到刪除區即可刪除。
- 點擊 `刪除全部` 會重設為一個預設元素。
- 支援匯出 `PNG`、`SVG` 和 `JSON`。
- 匯入 `JSON` 可以恢復存檔，並盡可能相容舊版本資料。

## 行動裝置提示
- 當 SVG 寬度超過螢幕時，可以在預覽區橫向滑動。
- 觸控裝置需要短按停留後再開始拖曳元素。
- 拖曳到預覽區左右邊緣附近時，畫布會自動捲動。
