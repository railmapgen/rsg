# 地铁导视生成器教程

## 基本操作
- 点击 `添加新块` 来新增元素。
- 在 SVG 预览区点击元素即可选中它。
- 右侧面板可以修改样式、分割线、整体对齐、宽度和特殊属性。
- 可以直接在 SVG 预览中拖拽元素来调整顺序。

## 编辑建议
- 部分带文字的元素会根据内容自动调整宽度。
- 支持手动宽度的元素，如果保持为 `自动`，会继续使用自动宽度。
- 样式选择窗口带有搜索栏，样式较多时建议直接搜索。
- 某些线路类元素在选择调色板后，会自动带出线路编号或名称。

## 预览与导出
- 将元素拖到删除区即可删除。
- 点击 `删除全部` 会重置为一个默认元素。
- 支持导出 `PNG`、`SVG` 和 `JSON`。
- 导入 `JSON` 可以恢复存档，并尽可能兼容旧版本数据。

## 移动端提示
- 当 SVG 宽度超过屏幕时，可以在预览区横向滑动。
- 触屏设备需要短按停留后再开始拖拽元素。
- 拖拽到预览区左右边缘附近时，画布会自动滚动。
