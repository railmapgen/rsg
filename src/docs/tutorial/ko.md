# 지하철 안내 표지 생성기 가이드

## 기본 사용법
- `새 요소 추가`를 눌러 요소를 추가합니다.
- SVG 미리보기에서 요소를 클릭하면 선택할 수 있습니다.
- 오른쪽 패널에서 스타일, 분할선, 전체 정렬, 너비, 특수 속성을 수정할 수 있습니다.
- 요소는 SVG 미리보기 안에서 직접 드래그하여 순서를 바꿀 수 있습니다.

## 편집 팁
- 일부 텍스트 요소는 내용에 따라 너비가 자동으로 조정됩니다.
- 수동 너비를 지원하는 요소는 `자동` 상태로 두면 자동 너비를 사용합니다.
- 스타일 선택 창에는 검색창이 있습니다.
- 일부 노선 요소는 팔레트를 선택하면 노선 번호나 이름이 자동으로 채워집니다.

## 미리보기와 내보내기
- 요소를 삭제 영역으로 드래그하면 삭제됩니다.
- `모두 삭제`를 누르면 기본 요소 하나로 초기화됩니다.
- `PNG`, `SVG`, `JSON`으로 내보낼 수 있습니다.
- `JSON` 가져오기는 저장 내용을 복원하며, 가능한 범위에서 이전 버전 데이터도 호환합니다.

## 모바일 안내
- SVG 너비가 화면보다 크면 미리보기 영역을 가로로 스와이프할 수 있습니다.
- 터치 기기에서는 잠시 누른 뒤 드래그를 시작하세요.
- 드래그 중 좌우 가장자리로 가까이 가면 미리보기가 자동으로 스크롤됩니다.
